Box-Sizing Comparison

content-box

Content Box Width: 280px content

The padding and border are added outside the declared width.

border-box

Border Box Width: 280px total

The declared width includes the content, padding, and border.

Explanation: With content-box, the total width is 280 + 50 padding + 20 border = 350px. With border-box, the total width remains 280px because padding and border are included in the declared width.
